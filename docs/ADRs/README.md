# Architecture Decision Records (ADRs)

This directory contains Architecture Decision Records (ADRs) for the Data Ingestor project. ADRs document significant architectural and technical decisions made during development.

## Format

Each ADR follows this structure:
- **Title**: Clear, concise description
- **Status**: Proposed, Accepted, Deprecated, Superseded
- **Context**: Problem or situation prompting the decision
- **Decision**: What was decided and why
- **Consequences**: Positive and negative impacts
